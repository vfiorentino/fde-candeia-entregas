# Certificação FDE · Case Candeia · materiais e entregas

Repositório de entregas dos hotseats 07 e 08 da Certificação FDE, Delta Academy. A Candeia Materiais Elétricos é um caso fictício e os valores são ilustrativos.

A entrega é opcional: cada um pode entregar o próprio memo em uma pasta, por pull request.

## Como entregar

1. Faça um fork deste repositório.
2. Copie `hotseat-07/_modelo-grupo/` para `hotseat-07/seu-nome/`. Use letras minúsculas e hífen, por exemplo `hotseat-07/ana-souza/`.
3. Preencha o `README.md` da pasta com o seu nome e a decisão em uma frase.
4. Coloque os arquivos da entrega na pasta. A lista está em [hotseat-07/README.md](hotseat-07/README.md).
5. Abra um pull request com o título `Hotseat 07 · Seu nome`.

Mexa só na sua pasta. O professor faz o merge depois da correção.

## Rodar o kit

Precisa de Node 20 ou mais novo e de acesso à Runflow (`rf login` ou `RUNFLOW_API_KEY`). As instruções estão em [kit-runflow-candeia/README.md](kit-runflow-candeia/README.md).
